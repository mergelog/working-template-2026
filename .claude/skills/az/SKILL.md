# az解説

特に行の指定がない場合、全行を対象に「末尾解説コメント」を追加する
行が指定されている場合や「選択行」等のの指定がある場合、その行のみに「末尾解説コメント」を追加する
- コメントアウトの指定は //:: とする
- コメントにコメントは不要
- 閉じタグにコメント不要
- 解説は 各観点 等を、ユーザのレベルに合わせ臨機応変な粒度で記載する
- コメントに敬語は不要
  ```ts
  import {
    ChangeDetectionStrategy, //:: 変更検知戦略（OnPush指定）に使う列挙
    Component, computed, input, //:: コンポーネント定義／派生Signal／入力Signal
  } from '@angular/core';
  ```
