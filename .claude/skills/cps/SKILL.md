# cps解説

./90_samples にコンポーネント作成してサンプルコード作成
dashboardからそのサンプルにリンク追加

コンポーネント名
learn-{連番2桁}-{関数名など}

- コードコメント不要
- サンプルコードは、努めてシンプルにし、複雑化してはならない。
- 不要なスタイル（scss等）は追加しない
- コンポーネントフォルダに別に .concept.md ファイルを作成しファイル名で概要を表現する
x_{概要}.concept.md

- ファイル内には以下を記載。記載文章は短い方が良い
  + 関数詳細
  + どういうケースで使用するか
  + 注意点
